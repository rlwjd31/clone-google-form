# 설치

```shell
$) yarn install
$) yarn switch dev
$) yarn dev
```

요구사항과 아래의 추가사항을 만족하는 기능 구현.

- 양식 지우기(preview모드 => localStroage와 새로고침으로 구현)
- 질문 데이터 저장 (브라우저 새로고침 시 유지)
- 사용자 친화적인 UI/UX(google form의 사용자 상호작용시)
  - icon hover시 tooltip 생성
  - input focus및 hover시 style 적용
  - tab을 이용한 기능
  - 해당 질문란 focus시 어떤 질문란에 위치하는지 알려주는 기능
